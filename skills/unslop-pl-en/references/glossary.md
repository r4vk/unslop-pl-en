# Glossary: PL <-> EN

A seed list for IT, project management, AI regulation and the Polish energy market. Use it for Translate, Verify translation, and when choosing between a foreign term and a Polish one.

How to extend: add rows in the same table, keep one preferred rendering per row, and note the context. When a project needs a term not listed, ask once, then add it. Verify official names against the current documents of the institution before publishing; names and acronyms change.

## Words that sound like jargon but have plain Polish equivalents

| English habit | Polish |
|---|---|
| butikowy (boutique) | niewielki i wyspecjalizowany |
| champion | lokalny ekspert, osoba wspierająca wdrożenie |
| klocki | elementy, części, moduły |
| hands-on | praktyczny, na realnych zadaniach |
| kick-off | rozpoczęcie, spotkanie otwierające |
| roadmapa | plan rozwoju (roadmap accepted in product teams) |
| onboarding | wdrożenie nowej osoby / wdrożenie do pracy (onboarding accepted in IT) |
| stakeholder | interesariusz |
| outcome, deliverable | efekt, rezultat; produkt pracy |
| finance leaders | osoby kierujące finansami (not "liderzy finansowi"; "dyrektorzy finansowi" only if the source means CFOs) |
| month-end close | zamknięcie miesiąca (księgowe) |
| guided setup | konfiguracja z przewodnikiem / prowadzona konfiguracja; use the product's own name for it if it has one |
